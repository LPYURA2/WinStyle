# WS-03A — первый контролируемый host probe
Собственный PE fixture компилируется clang/lld-link без CRT и импортов. Build-time узкий валидатор извлекает единственную .text, встраивает в отдельный host child; child выделяет RW, копирует, переводит RX и вызывает Microsoft x64 ABI. Режимы: арифметика, машинная инструкция trap, бесконечный цикл pause. Supervisor ограничивает время 1.5 s и убивает группу, собирает код/сигнал и ограниченный вывод; child выставляет RLIMIT_CORE/CPU/AS/FSIZE. Вывод проверяется отдельно C host режимом. 6 тестов (ожидаемо 143), CI пока не подтверждён; локально не запускалось.
Это только trusted fixture. Файл child и сборочные исходники должны быть доверенными; нет проверки происхождения бинарника. Нет seccomp, namespace, защиты syscalls, ограничения файлов/сети, полноценной изоляции, TEB/PEB/TLS/SEH, Win32 API, исполнения IAT/DLL. Нельзя запускать неизвестные EXE. Ограничения ресурсов — экспериментальные, timeout зависит от host. Не готовая Windows-среда. GCC/Clang sanitizer прежней проверки относятся к WS-01, новый child отдельно не покрыт. Следующий этап после проверки — формальный контракт изоляции и контролируемый импорт простейшего API на собственном fixture. StyleOS и ядро не меняются.
