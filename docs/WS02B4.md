# WS-02B4 — статическое связывание IAT
PE32+ AMD64, явный каталог и модельные адреса. Сохраняются типизированные импорты, RVA слотов и терминаторов, RVA релокаций. Размещение DLL только по явному opt-in. Общий лимит образов 64 МиБ, на образ 32 МиБ; предпочитаемые базы или явно заданные, коллизии отклоняются. Применяются разрешённые адреса base+RVA в обычном массиве, после проверки слотов (границы IAT, совпадение с ILT, отсутствие перекрытия, неисполняемая секция, пересечение с релокациями и каталогами). Результат immutable, без изменения входа или выдачи частичного результата. Для тестового bridge.dll задан отдельный preferred base; произвольного автоматического размещения пока нет. 15 новых тестов, ожидаемо 129; не запускались локально, CI проверить. Ограничения: строгий профиль (IAT directory обязателен, даже если Windows допускает иное), не проверены все пересечения структур, IAT fuzz и обычные циклы импортов ещё отдельно не проверены. Не исполняется код, нет защиты процесса, Windows API, TLS/init/delay imports. Не считать готовым loader.
