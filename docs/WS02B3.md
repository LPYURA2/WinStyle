# WS-02B3 — статический резолвер
Предложенная реализация: immutable EXE/DLL, явный каталог без поиска по файловой системе, нормализация ограниченного ASCII basename (без путей), различение ordinal и буквального имени, ленивый статический анализ только нужных модулей, очередь транзитивных импортов, разрешение forwarder и контроль циклов по module+ordinal. Не выдаёт адреса хоста, только RVA; IAT не изменяет. Лимиты: 64 модуля, 128 МиБ каталога, 65536 единиц работы, 32 перенаправления. 16 новых тестов, ожидаемо 106 суммарно, CI проверить; локальный запуск не выполнен. Ограничения: не все допустимые имена DLL, нет Windows search order/API sets, delay/bound import, SxS, TLS, init или runtime; бюджеты экспериментальны. Реальные транзитивные графы, длинные цепочки и fuzz модели ещё не покрыты. Статическая проверка не означает разрешение исполнения.
