# Концепция WinStyle v0.1 — актуализированная текстовая версия
Первоначальная концепция от 27.11.2026. Согласовано: самостоятельное направление, скачал EXE → установил → запустил → работаешь. Не требуется вручную настраивать VM, контейнеры, префиксы, DLL или отдельную Windows. Установка через штатный интерфейс, меню приложений, удаление через настройки. EXE не нужно конвертировать в .tea; .tea остаётся родным форматом. Независимое обновление WinStyle, отказ приложения не должен обрушать оболочку или ядро.
Репозиторий создан владельцем: LPYURA2/WinStyle (публичный). Разработка автономная, интеграция только после согласования интерфейсов и независимой приёмки. Архитектура, библиотеки и сроки пока не утверждены. Приоритет исследования — нативное исполнение x86-64 с Windows ABI/API; ARM потребует отдельной стратегии. Сравнивать собственную реализацию, открытые компоненты и гибрид по покрытию API, производительности, безопасности, переносимости и лицензиям.
Нейтральность к источнику приложения: не проверять покупку, не вмешиваться в активацию. Одинаковые политики безопасности, ограниченные права, контроль доступа к файлам, сети и устройствам. Пользователь отвечает за источник и соблюдение лицензий, что не снимает обязанностей разработчика по безопасности и применимому праву. Не распространять кряки, активаторы, утечки Windows или чужие бинарники без права распространения. Вести реестр зависимостей/лицензий, проверить уведомления перед выпуском.
Тесты: собственные EXE, 7-Zip, Notepad++, VLC, GIMP; сложный эталон FL Studio (оригинальный установщик и разрешённая лицензией версия). Проверять установку, запуск, UI, звук, MIDI, VST, открытие/сохранение проектов, экспорт с учётом ограничений пробной версии. Негативные тесты: повреждённый PE, отсутствующая DLL, запрещённый доступ, зависание, аварийное завершение, удаление. Приёмка по конкретным версиям, журналам, сохранности данных, отсутствию отказа ядра и замерам CPU/RAM/запуска. Универсальная совместимость не обещана. GTA 6 не является подтверждённой целью текущей приёмки.
