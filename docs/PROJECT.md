# WinStyle: единая точка входа
Порядок чтения: корневой README → AGENTS → STATE → NEXT → CONCEPT → ARCHITECTURE → ROADMAP → отчёт последнего этапа. Проверить реальные SHA и GitHub Actions перед работой. Не полагаться на историю чатов.
Цель: прозрачная установка и запуск Windows EXE в StyleOS, с нативной интеграцией и безопасностью. Архитектура пока исследовательская. В main только код, прошедший критерии текущего этапа; документацию можно уточнять отдельно с сохранением проверенного кода. Каждый этап в отдельной ветке, корневой README ветки описывает её назначение, изменения, тесты, ограничения и следующий шаг. Перед принятием проверять конкретный SHA, не смешивать CI другой ветки и локальные результаты. После принятия обновить STATE, NEXT, HISTORY. Не удалять историю. Не использовать main как экспериментальную ветку.
Ограничение владельца: единственный репозиторий LPYURA2/WinStyle. Никаких обращений к LPYURA2/OS, изменений системы, ядра или их сборок. Реальную интеграцию не начинать без отдельного разрешения. Проект публичный: не загружать секреты, личные данные, нелицензионные бинарники.
