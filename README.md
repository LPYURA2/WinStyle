# WinStyle
Подсистема совместимости Windows-приложений для StyleOS.

**Скачал → установил → запустил → работаешь.** Без ручной настройки VM, контейнеров, префиксов и библиотек. WinStyle — отдельное направление, не самостоятельная гостевая Windows. Пока лабораторный прототип, не готовый runtime.

## Ветки
main — проверенная лабораторная база. Каждый новый этап — отдельная ветка feature/ws..., собственный README, отчёт и тесты. Историю не удалять. Не считать зелёный CI доказательством полной безопасности.
## Воспроизведение
Linux x86-64, Python 3.10+, clang, lld-link, cc; GCC для sanitizer. `sh run.sh`, `sh run_sanitizers.sh`. Статический анализ: `python3 pecheck.py FILE.exe`. Только собственная тестовая функция исполняется в WS-01. Произвольные EXE не исполняются. Python выбран временно для исследовательского парсера.
## Граница
Работа только в LPYURA2/WinStyle. Не обращаться к LPYURA2/OS и не менять StyleOS или ядро. Интеграция только по отдельному разрешению владельца.
