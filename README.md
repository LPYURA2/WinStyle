# WinStyle

Автономное исследование совместимости Windows-приложений для StyleOS. Цель: скачал EXE, установил, запустил, работаешь. Без ручной настройки VM, контейнеров и префиксов.

Работа исключительно в LPYURA2/WinStyle. StyleOS и ядро не изменяются. См. AGENTS.md.

## WS-02A
Лабораторный PE32+ AMD64 валидатор на Python и эксперимент прямого исполнения собственного тестового PE на Linux x86-64. Не запускает произвольные приложения. Python 3.10+, clang, lld-link, cc. Запуск тестов: sh run.sh. Дополнительно sh run_sanitizers.sh (GCC и Clang; в Clang отключена проверка function у иностранного машинного кода, остальные проверки включены). Исходные отчёты и концепция остаются в локальном архиве WinStyle_WS02.zip. Ограничения: статическая проверка не гарантирует безопасность; DLL, экспорты и другие каталоги ещё требуют доработки; никаких тестов в StyleOS.

Спецификация: https://learn.microsoft.com/en-us/windows/win32/debug/pe-format
