# Дорожная карта

WS-01 — прямое исполнение собственного минимального PE, лабораторный результат.
WS-02A — ограниченный статический валидатор, импорт базы.
WS-02B — DLL, экспорты, расширенные импорты, модель размещения без исполнения.
WS-03 — изолированная среда исполнения, минимальный Win32 API.
WS-04 — DLL, память, потоки.
WS-05 — файлы и реестр.
WS-06 — графические приложения.
WS-07 — установщики.
WS-08 — сеть, звук, буфер обмена.
WS-09 — 32-битные программы.
WS-10 — графические API, сложные приложения.
WS-11 — оптимизация, приёмка.

Архитектура предварительная. Интеграция в StyleOS только по отдельному разрешению.
